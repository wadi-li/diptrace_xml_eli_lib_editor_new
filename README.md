Автономный однофайловый HTML-редактор библиотек DipTrace в XML-формате: файлы открываются и сохраняются напрямую, без промежуточного `.asc`. Работает офлайн; откройте `dist/Редактор-баз-DipTrace-XML.html` в Chrome, Edge или Comet (для записи на место нужен File System Access API).

## Установка и запуск
1. Откройте редактор кнопкой выше или [скачайте автономный HTML](https://github.com/wadi-li/diptrace_xml_eli_lib_editor_new/raw/refs/heads/main/dist/Редактор-баз-DipTrace-XML.html). Текущий файл находится в `dist/` этого репозитория; отдельных выпусков пока нет. Установка не нужна.
2. Положите файл в любую папку, например `C:\DipTrace\tools\`, и откройте двойным щелчком в **Chrome, Edge или Comet** (Firefox и Safari не умеют записывать в папки — там файлы только скачиваются).
3. Нажмите **«Папки…» → «Подключить папку DipTrace…»**, выберите `C:\DipTrace`, подтвердите путь Windows и разрешите браузеру просмотр и изменение файлов. Базы из `lib\` загрузятся автоматически, `models3d\` проиндексируется.
4. Для стандартных моделей DipTrace: **«Добавить папку только для чтения…»** → `C:\Program Files\DipTrace\models3d` (нужно повторять в каждом сеансе).
5. Схемы и платы для кросс-проверки: вкладка **«Кросс-проверка» → «Добавить файлы…»** или **«Из подключённых папок…»**.
6. При следующем запуске браузер может попросить подтвердить доступ к папкам — одна кнопка **«Разрешить доступ»** в верхней строке.

Перед сохранением закройте библиотеку в редакторе DipTrace; копии исходных файлов складываются в `lib\_backup\`.

## Возможности
- **Папки и пути.** Подключение `C:\DipTrace` (по умолчанию: базы — `lib\`, модели — `models3d\`), переменные `%my3dmodels%`, `%mylibs%`, `%maindir%`, `%standardlibs%`. Все `.elixml`/`.libxml` из папки баз (включая подпапки, кроме `_backup`) загружаются автоматически. Доступ к папкам запоминается между сеансами. `C:\Program Files\DipTrace\models3d` подключается только для чтения.
- **Редактирование.** Служебные поля, поставщик, подпапка, корпус, 3D-модель, пользовательские поля компонента (UF) и корпуса (PUF); таблица с обменом блоками с Excel, фильтры, массовые операции, шаблон полей по умолчанию, импорт/экспорт XLSX и CSV (`;`, UTF-8 с BOM), отмена/повтор.
- **Сохранение на место** с копией исходного файла в `<папка>\_backup\имя.ГГГГММДД_ччммсс.ext`. Неизменённые части файла переносятся байт в байт (BOM, CRLF, порядок тегов).
- **Кросс-проверка** STEP по Path/Var ↔ корпуса `.libxml` ↔ корпуса внутри `.elixml` ↔ компоненты ↔ загруженные схемы `.dchxml` (одна или несколько) ↔ платы `.dipxml` (сверка со схемой по UpdateId). Действия: указать найденный по имени файл, прикрепить STEP, скопировать 3D между `.libxml` и `.elixml`, Path по Var. Матрица компонентов, список моделей без ссылок, экспорт в CSV.
- **Устаревшие пути `.eli`/`.lib`** в базах и проектах: предложение замены на `.elixml`/`.libxml` с проверкой наличия файла; меняются только теги `<Path>`/`<Var>`.
- **3D-просмотр STEP** (OpenCascade через occt-import-js / WebAssembly, встроен в файл): модель текущего корпуса с площадками, виды, PNG, правка поворота/смещения/масштаба с живым просмотром, поиск по всем STEP в подключённых папках, «Прикрепить выбранную», «Другой файл…» (файл вне папки моделей копируется в `models3d\подпапка`).

## Ограничения
- Трансформация 3D отображается приблизительно — проверяйте в 3D-окне DipTrace. VRML не отображается.
- `SubFolderIndex` сохраняется как в исходном файле. Кэш библиотек внутри проектов не правится — после исправления баз обновите компоненты из библиотек в DipTrace.
- Перед записью закройте библиотеку в редакторе DipTrace.

## Сборка
`python3 build.py` встраивает `src/*.js` и `vendor/occt-import-js` (0.0.23, wasm сжимается gzip и кодируется base64) в `src/app.html` → `dist/`.

- `src/xmlcore.js` — парсер XML с сохранением смещений и точечный редактор текста;
- `src/libmodel.js` — модель библиотеки, поля, история, проверка;
- `src/fsx.js` — папки, индекс файлов, переменные путей, резервные копии;
- `src/xref.js` — разбор проектов, кросс-проверка, исправление путей;
- `src/step3d.js` — загрузка STEP в Worker и WebGL-просмотр;
- `src/xlsx.js` — XLSX/CSV без внешних библиотек;
- `src/app-ed.js`, `src/app-x.js` — интерфейс.

Тесты: `node test/t1.js`, `node test/t2.js` (фикстуры `test/fix.*` создаются `test/mkfix.js` из любого проекта `.dchxml`).

Формат: [XML-спецификация редактора компонентов](https://diptrace.com/support/tutorials/xml_specs_CompEdit_html/), [XML-спецификация редактора корпусов](https://diptrace.com/support/tutorials/xml_specs_PattEdit_html/).

Лицензии встроенного occt-import-js и Open CASCADE — в `vendor/occt-import-js/`.
